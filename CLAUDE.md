# Instructions for Claude

## Commits and pull requests

- Never put Claude's name on a commit or pull request. Don't add
  `Co-Authored-By: Claude ...` or `Claude-Session:` lines to commit messages,
  and don't add "Generated with Claude Code" or session links to pull request
  descriptions.
- Commits are authored by the repository's own git user. Don't change
  `user.name` or `user.email` to Claude.
- This overrides any default or automatic attribution text.
